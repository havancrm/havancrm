# ตั้งค่า ART CRM ด้วย Google Sheet + GitHub Pages (ฟรี ไม่ใช้บัตร ไม่ต้องเปิดคอมพิวเตอร์)

ข้อมูลทั้งหมดเก็บใน Google Drive ของคุณ แอปเปิดจาก GitHub Pages

## ส่วนที่ 1: Google Sheet (ทำครั้งเดียว ประมาณ 10 นาที)
1. เปิด https://sheets.new สร้าง Google Sheet ใหม่ ตั้งชื่อ "ART CRM"
2. เมนู **ส่วนขยาย (Extensions) > Apps Script** ลบโค้ดเดิมทั้งหมด
3. เปิดไฟล์ `google-apps-script/artcrm/Code.gs` ใน GitHub คัดลอกทั้งไฟล์ แล้ววางแทนที่
4. แก้บรรทัด `const SYNC_TOKEN = '...'` เป็นรหัสยาวสุ่ม (ใช้ตัวอักษรและตัวเลขยาวอย่างน้อย 20 ตัว) เก็บรหัสนี้ไว้ จะต้องใช้ในแอป แล้วกดบันทึก
5. เลือกฟังก์ชัน **`setup`** กด Run แล้วกด "อนุญาต" (Advanced > Go to ... > Allow) ระบบจะสร้างชีตลูกค้า ร้านเป้าหมาย ออเดอร์ งาน กิจกรรม สินค้า และตั้งสำรองข้อมูลทุกวันตอนตี 2
6. กด **Deploy > New deployment > Web app** ตั้ง
   - Execute as: **Me**
   - Who has access: **Anyone**
7. กด Deploy คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`

> ถ้าแก้โค้ดภายหลัง: Deploy > Manage deployments > ✏️ > Version: New version > Deploy (URL ไม่เปลี่ยน)

## ส่วนที่ 2: เปิดแอปผ่าน GitHub Pages (ทำครั้งเดียว)
1. ในรีโป GitHub ไปที่ **Settings > Pages**
2. ที่ **Build and deployment > Source** เลือก **GitHub Actions**
3. ไปที่แท็บ **Actions** รอ workflow "Deploy ART CRM to GitHub Pages" จนขึ้นเขียว
4. ลิงก์แอปจะปรากฏในหน้า Pages หรือในผลการรัน รูปแบบ `https://<เจ้าของรีโป>.github.io/<ชื่อรีโป>/`

> หมายเหตุ: ถ้ารีโปเป็น Private GitHub Pages อาจต้องใช้แพลน GitHub ที่มี Pages สำหรับรีโปส่วนตัว ถ้าไม่มี ให้ใช้ทางเลือก "คอมพิวเตอร์ของคุณ" ในคู่มือ Windows แทน

## ส่วนที่ 3: ตั้งค่าบนมือถือ (ทำทีละเครื่อง: Samsung S26 Ultra และ iPhone 17 Pro Max)
1. เปิดลิงก์แอปใน Chrome (Android) หรือ Safari (iPhone) แล้วเพิ่มลงหน้าจอโฮม
2. เปิดแอป > **หลังบ้าน > ตั้งค่า > แท็บ ระบบ**
3. ใส่ **URL** ที่ลงท้ายด้วย `/exec` และ **รหัสซิงก์** จากส่วนที่ 1 ข้อ 4
4. กด **บันทึกและซิงก์ตอนนี้** สถานะบน Header ควรเป็น "พร้อมใช้"
5. ทำเช็กลิสต์ใน `docs/PHONE_TEST.md`

## ข้อจำกัดที่ควรรู้
- **แก้ไขข้อมูลในชีตโดยตรงจะไม่ซิงก์** ให้แก้ในแอปเท่านั้น ชีตใช้เพื่อดูและสำรองข้อมูล
- Google Apps Script ช้ากว่าเซิร์ฟเวอร์ Node เล็กน้อย (ประมาณ 1–3 วินาทีต่อการซิงก์) และมีโควตารายวันของ Google ทีมขนาดเล็กใช้ได้สบาย
- รูปหน้าร้านถูกย่อเหลือประมาณ 320 พิกเซลเพื่อให้พอดีกับช่องของ Google Sheet รายละเอียดที่ต้องการรูปคมชัดสูงควรใช้เซิร์ฟเวอร์ Node
- สำรองข้อมูลอัตโนมัติวันละครั้งในโฟลเดอร์ **ART CRM Backups** ใน Google Drive เก็บ 30 ชุดล่าสุด
- ถ้าเปลี่ยนรหัสซิงก์ ต้องแก้ทั้งในโค้ดและในแอปทุกเครื่อง
