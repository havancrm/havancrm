# ART CRM — checklist ทดสอบบนมือถือจริง

ทดสอบก่อนใช้งานจริงทุกครั้ง บันทึกผลในช่อง "ผล" (✓ ผ่าน / ✗ ไม่ผ่าน + หมายเหตุ)

## 0. เตรียมการ
- เปิดแอปผ่าน HTTPS เท่านั้น (กล้อง GPS และ Service Worker ต้องใช้ HTTPS)
  - วิธีเร็วที่สุด: ลากโฟลเดอร์ `app/` ไปวางที่ app.netlify.com/drop
  - หรือรัน `SYNC_TOKEN=... npm start` แล้วเปิดผ่าน Cloudflare Tunnel / Caddy
- ทดสอบทั้ง **iPhone Safari** และ **Android Chrome**
- ทดสอบกับข้อมูลจริงอย่างน้อย 1,000 ราย (ไม่ใช่ข้อมูลตัวอย่าง) และเปิดขนาดตัวอักษรระบบปกติ
- ทดสอบที่ความกว้าง 360, 390, 430 px (หรือเครื่องจริงที่ใกล้เคียง)

## 1. เปิดแอปและเพิ่มลงหน้าจอโฮม
| ข้อ | ขั้นตอน | ผลที่ควรเห็น | ผล |
|---|---|---|---|
| 1.1 | เปิดลิงก์ครั้งแรก | ไม่มีหน้าขาว, ขึ้น "ART CRM" ภายในไม่กี่วินาที | |
| 1.2 | เพิ่มลงหน้าจอโฮม แล้วเปิดจากไอคอน | เปิดแบบเต็มจอ (standalone) ไม่มีแถบเบราว์เซอร์ | |
| 1.3 | ปิดแอปแล้วเปิดใหม่ | ข้อมูลยังอยู่ แสดงทันที | |
| 1.4 | เปิดโหมดเครื่องบิน แล้วเปิดแอปใหม่ | เปิดได้ และค้นหา/เปิดลูกค้าได้ | |

## 2. Header และการซิงก์
| ข้อ | ขั้นตอน | ผลที่ควรเห็น | ผล |
|---|---|---|---|
| 2.1 | ตั้งค่า → ระบบ → ใส่ URL ฐานกลาง → บันทึก | สถานะเป็น "พร้อมใช้" หรือ "กำลังบันทึก" แล้ว "พร้อมใช้" | |
| 2.2 | สร้างลูกค้า 1 ราย ขณะออนไลน์ | ขึ้น "รอบันทึก" แล้วกลับเป็น "พร้อมใช้" ภายใน ~3 วินาที | |
| 2.3 | สร้างออเดอร์ขณะเปิดโหมดเครื่องบิน | ข้อมูลบันทึกได้ สถานะเป็น "ออฟไลน์" หรือ "รอบันทึก" | |
| 2.4 | ปิดเครื่องบิน แล้วรอ | ออเดอร์ขึ้นในฐานกลาง (ตรวจในชีตหรือเซิร์ฟเวอร์) | |
| 2.5 | กดสถานะบน Header | เปิดหน้า "สถานะการบันทึก" อ่านรู้เรื่อง | |
| 2.6 | แก้ลูกค้าเดียวกันจากสองเครื่อง | เครื่องหลังเห็นแบนเนอร์ "ข้อมูลนี้ถูกแก้จากอีกเครื่อง" (หรือรวมให้เอง) | |
| 2.7 | ทดสอบ "ใช้ข้อมูลของฉัน" / "ใช้ข้อมูลล่าสุด" | แบนเนอร์หายและข้อมูลตรงกับที่เลือก | |

## 3. หน้าหลักและค้นหา
- [ ] ค้นหาด้วยชื่อ เบอร์ รหัส ที่อยู่ เลขออเดอร์ SKU แล้วผลขึ้นเร็ว (ไม่หน่วง)
- [ ] กดผลค้นแล้วเปิดหน้ารายละเอียดทันที
- [ ] การ์ด "งานวันนี้" กดแล้วเปิดรายการที่เกี่ยวข้อง
- [ ] ปุ่มด่วน 4 ปุ่มทำงานถูกต้อง

## 4. ลูกค้า
- [ ] รายการลูกค้าเลื่อนลื่น ไม่หน่วงเมื่อมีลูกค้า 1,000+ ราย (กด "แสดงเพิ่ม")
- [ ] ตัวกรองทุกตัวทำงาน และล้างตัวกรองได้
- [ ] โทร / นำทาง / รับออเดอร์จากการ์ดทำงาน (โทรแล้วมีกิจกรรม "โทรออก")
- [ ] เพิ่มลูกค้า: เพิ่มเบอร์ได้หลายเบอร์, ถ่ายรูปหน้าร้านจากกล้อง, เก็บพิกัด (ออกนอกอาคารแล้วดูค่าความแม่นยำ)
- [ ] เบอร์ซ้ำถามก่อนบันทึก
- [ ] ปุ่มนัด / เข้าพบ / ติดตาม บันทึกลงไทม์ไลน์

## 5. ร้านเป้าหมาย
- [ ] เพิ่มร้าน, บันทึกผลติดตาม (เปลี่ยนสถานะได้), สร้างนัด
- [ ] เสนอสินค้า: เลือกหลายรายการ แล้วบันทึก
- [ ] เปลี่ยนเป็นลูกค้า: ถ้าเบอร์ซ้ำ ต้องเลือก "ใช้รายนี้" หรือ "สร้างใหม่"

## 6. รับออเดอร์ (สำคัญที่สุด)
- [ ] เลือกร้านจากการค้นหา แล้วกด "เปลี่ยนร้าน" ระบบถามก่อนล้างสินค้า
- [ ] "ใช้ออเดอร์ล่าสุด" และปุ่มสินค้าที่ซื้อประจำทำงาน
- [ ] เพิ่มสินค้าจากการค้นหา, ปรับจำนวนด้วย − / +, พิมพ์จำนวนเองได้ (แป้นพิมพ์ไม่บังช่องกรอก)
- [ ] VAT (ไม่มี / รวม / +VAT) คำนวณถูกต้อง
- [ ] แถบด้านล่าง (sticky) ไม่ทับปุ่มและไม่ทับแป้นพิมพ์
- [ ] ปิดแอปกลางคันขณะกรอกออเดอร์แล้วเปิดใหม่ ร่างยังอยู่
- [ ] บันทึกแล้วกดซ้ำไม่สร้างออเดอร์ซ้ำ
- [ ] "เปิด LINE": ข้อความถูกคัดลอก และ LINE เปิดไปยังร้านที่ตั้ง LINE ID ไว้
- [ ] "ส่งรูป": แชร์ได้ (iPhone Share Sheet) หรือเปิดรูปเต็มแล้วบันทึกได้
- [ ] รูปใบสั่งซื้ออ่านออกชัดและตัวไทยไม่เพี้ยน
- [ ] ยกเลิกออเดอร์ต้องเลือกเหตุผล และออเดอร์ยังอยู่ในประวัติ
- [ ] "เปิดบิลแล้ว" ล็อกไม่ให้แก้ไข

## 7. งาน, รอบลูกค้า, แผนที่, เก็บข้อมูลหน้าร้าน
- [ ] งาน: เสร็จ / เลื่อน ทำงาน และรายการเลยกำหนดขึ้นสีแดง
- [ ] รอบลูกค้า: "เลื่อน 7 วัน" ทำให้รายการหายไปจากกลุ่มเลยรอบ
- [ ] แผนที่: "ใกล้ฉัน" ขออนุญาตตำแหน่งแล้วเรียงตามระยะ, ซูมเข้า/ออกได้, แตะจุดแล้วเปิดรายละเอียด
- [ ] เก็บข้อมูลหน้าร้าน: ถ่ายรูปจากกล้องหลัง, เก็บพิกัด, "หาพิกัดใหม่" ทำงาน

## 8. ประวัติซื้อ, แจ้งยอด, วิเคราะห์, ยอดขาย, สินค้า
- [ ] ประวัติซื้อ: กรองวันที่ สถานะ SKU ทำงาน
- [ ] แจ้งยอด: เลือกบิลได้, ยอดรวมถูก, คัดลอก/แชร์ข้อความได้, PDF เปิดหน้าพิมพ์
- [ ] วิเคราะห์: CSV ดาวน์โหลดได้และเปิดใน Excel ได้ (ภาษาไทยไม่เพี้ยน)
- [ ] ยอดขายรวม: ตั้งเกณฑ์ราคาแล้วตัวเลขเปลี่ยนตามจริง
- [ ] สินค้า: ตั้งราคามาตรฐานแล้วบันทึก

## 9. นำเข้า, สำรอง, กู้คืน
- [ ] นำเข้า CSV จาก Excel (บันทึกเป็น CSV UTF-8) อ่านหัวคอลัมน์ได้
- [ ] Preview แสดงแถวที่มีปัญหา และ "ข้ามแถวนี้" ทำงาน
- [ ] นำเข้าไฟล์เดิมซ้ำ ระบบเตือน
- [ ] สำรองอัตโนมัติก่อนนำเข้า ปรากฏในรายการสำรอง
- [ ] กู้คืน: หน้า Preview แสดงจำนวนก่อนยืนยัน และข้อมูลที่ไม่อยู่ในไฟล์ไม่ถูกลบ

## 10. ความเร็วและการใช้งานจริง
- [ ] เปิดแอปจนถึงหน้าหลัก ≤ 2 วินาที (ข้อมูลจริง)
- [ ] เปลี่ยนหน้าไม่หน่วงเกิน 0.5 วินาที
- [ ] หน้าจอ/แป้นพิมพ์ไม่บังช่องกรอก ทุกหน้า
- [ ] ไม่มีปุ่มซ้อนกันหรือข้อความล้น (ลองชื่อร้านยาวมาก ๆ)
- [ ] ระยะกดปุ่มสะดวกนิ้วหัวแม่มือ
