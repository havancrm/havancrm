# HavanCRM — แอปมือถือผู้ช่วยเซลล์

แอปช่วยเซลล์ขายบนมือถือ: **ข้อมูลลูกค้า · ออเดอร์ · ยอดขาย** ใช้งานได้ทั้งออนไลน์/ออฟไลน์
ซิงค์ข้อมูลข้ามเครื่องอัตโนมัติ และสำรองข้อมูลได้

## จุดเด่น
- **เร็ว (< 1 วินาที)** — ข้อมูลทั้งหมดอยู่ในหน่วยความจำของเครื่อง (local-first) ไม่ต้องรอเน็ต
  ทดสอบกับลูกค้า 500 ราย + ออเดอร์ 3,000 รายการ: เปิดแต่ละหน้า 8–45 ms, ค้นหา ~15 ms,
  เปิดแอปใหม่ทั้งหมด ~0.23 วินาที (มุมขวาบนแสดงเวลาประมวลผลของแต่ละหน้า)
- **ทำงานออฟไลน์** — เก็บใน IndexedDB + Service Worker ติดตั้งลงหน้าจอโฮมได้เหมือนแอป (PWA)
- **ซิงค์เหมือนข้อมูลในมือถือ** — แก้ไขที่เครื่องไหนก็ได้ ซิงค์อัตโนมัติทุก 60 วินาที / เมื่อแก้ไข /
  เมื่อกลับมาออนไลน์ / เมื่อเปิดแอป ใช้หลัก "ข้อมูลที่แก้ล่าสุดชนะ" ต่อรายการ
- **สำรองข้อมูล 3 ชั้น** — (1) ในเครื่อง (2) บนเซิร์ฟเวอร์ + สแนปช็อตรายวันเก็บ 30 วัน
  (3) ดาวน์โหลดไฟล์ `.json` ไปเก็บเอง และนำเข้ากลับได้

## ฟีเจอร์
| หน้า | ทำอะไรได้ |
|---|---|
| ยอดขาย | ยอดวันนี้ / เดือนนี้ (เทียบเดือนก่อน) / ค้างชำระ / จำนวนลูกค้า, กราฟ 7 วัน, ลูกค้า Top 5, ออเดอร์ล่าสุด |
| ลูกค้า | ค้นหาทันที (ชื่อ เบอร์ บริษัท แท็ก), ยอดซื้อรวม, ซื้อล่าสุด, ค้างชำระ, ปุ่มโทร / LINE, ประวัติการสั่งซื้อ |
| ออเดอร์ | สร้างออเดอร์เร็ว (เลือกลูกค้า, จำชื่อสินค้า+ราคาล่าสุด), ส่วนลด, สถานะ รอชำระ/ชำระแล้ว/ส่งแล้ว/ยกเลิก, กรอง+ค้นหา |
| ตั้งค่า | ตั้งค่าเซิร์ฟเวอร์ซิงค์, ซิงค์ทันที, สำรอง/กู้คืนไฟล์, สร้างข้อมูลตัวอย่าง |

## เริ่มใช้งาน
ต้องการ Node.js 18+ (ไม่มี dependency ภายนอก)

```bash
SYNC_TOKEN=รหัสลับของทีม PORT=8080 npm start
```
1. เปิด `http://<ที่อยู่เซิร์ฟเวอร์>:8080` บนมือถือ → เมนูเบราว์เซอร์ → **เพิ่มลงหน้าจอโฮม**
2. ไปที่ **ตั้งค่า** → ใส่ที่อยู่เซิร์ฟเวอร์และรหัสซิงค์ → บันทึก & ซิงค์
3. ทำแบบเดียวกันในทุกเครื่องของทีม ข้อมูลจะตรงกันทุกเครื่อง

> ใช้งานจริงควรวางเซิร์ฟเวอร์หลัง HTTPS (เช่น Caddy / Nginx / Cloudflare Tunnel) เพราะ Service Worker
> และการติดตั้งแอปบนมือถือต้องใช้ HTTPS ข้อมูลเซิร์ฟเวอร์อยู่ใน `server/data/` (ตั้งด้วย `DATA_DIR`)

## โครงสร้าง
```
app/      แอปมือถือ (PWA, ไม่ต้อง build)
  db.js     ฐานข้อมูลในเครื่อง: หน่วยความจำ + IndexedDB
  sync.js   ซิงค์สองทาง (push รายการที่แก้ไข / pull ตั้งแต่ cursor ล่าสุด)
  app.js    หน้าจอทั้งหมด
  sw.js     แคชให้เปิดได้ทันทีและออฟไลน์
server/   เซิร์ฟเวอร์ซิงค์ + สำรองข้อมูล (Node.js ล้วน)
test/     เทสต์ตรรกะการรวมข้อมูล (`npm test`)
```

## API
- `POST /api/sync` `{ since, changes: { customers: [], orders: [] } }` → `{ cursor, changes }`
- `POST /api/backup` สร้างสแนปช็อตทันที · `GET /api/health`
- ทุก request ต้องมี `Authorization: Bearer <SYNC_TOKEN>` เมื่อกำหนด `SYNC_TOKEN`
